      Welcome to DER

      DER draws a database as a diagram, from the JSON schema that the Framework generates.

      1. Add a schema from a json file, or from the url it is published at.
      2. Pick the tables in the list at the left and they show up on the canvas.
      3. Move them around, and gather the ones that belong together into a group.

      Everything stays in this browser, and comes back the way you left it.

      Select a Schema

      Use the button bellow to add a new Schema.

        Schema

        Name the Schema and select a json file or a schema url.

        You must complete the schema name.
        Upload file
        You must complete the schema main file.
        The file must be a valid JSON file.
        You must complete de main url.

        Remove Schema

        Do you really want to remove the selected Schema?

        Group

        A group gathers the tables that belong together, and none are selected yet.

        1. Pick the tables on the board, holding ctrl to add each one to the selection.
        2. Open this again and the group takes the tables that are picked.
        You must complete de name of the group.
        You must indicate at least one table.

        Remove Group

        Do you really want to remove the selected Group?

        View

        You must complete the name of the view.

        Remove View

        Do you really want to remove the selected View and its board?
