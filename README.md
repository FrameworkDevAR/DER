# DER

A diagram of a database, drawn from the JSON schema that the Framework generates: pick
the tables, arrange them on a board, gather them into groups and keep a view of each part
of the database. Everything stays in the browser, and comes back the way you left it.

**[Open DER →](https://der.frameworkphp.com.ar/)**

**[Read about the Framework →](https://frameworkphp.com.ar/)**

**[Read how the Framework writes the schema →](https://frameworkphp.com.ar/database/schema-json.html)**
